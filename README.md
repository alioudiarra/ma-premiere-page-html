# 🌱 Mon premier site HTML

Ceci est **mon tout premier repo GitHub** : un petit site de test réalisé il y a environ 2 ans, quand j'ai commencé à apprendre le développement web.

Il contient ma **toute première page en HTML**, avec un titre, une phrase… et beaucoup d'enthousiasme 😄

## 👀 Aperçu

La page affiche :

- un titre : **« MON beau site »**
- un message : *« un site fait que par moaaaaa !!!!! love to code »*

## 🎯 Pourquoi ce projet ?

- Découvrir les bases du HTML
- Comprendre comment structurer une page web
- Lier une feuille de style CSS à une page
- Faire mes premiers pas avec Git et GitHub

## 🛠️ Technologies utilisées

- **HTML5**
- **CSS** (fichier `style.css`)

## 📁 Structure du projet

```
.
├── index.html   # ma première page
└── style.css    # la feuille de style
```

## 🚀 Lancer le projet

1. Clone le repo :
   ```bash
   git clone https://github.com/TON-PSEUDO/NOM-DU-REPO.git
   ```
2. Ouvre le dossier du projet.
3. Double-clique sur `index.html` pour l'ouvrir dans ton navigateur.

Aucune installation n'est nécessaire.

## 📚 Ce que j'ai appris

- La structure d'un document HTML (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Les balises de base : `<meta>`, `<title>`, `<h1>`, `<div>`
- Comment relier un fichier CSS avec `<link rel="stylesheet">`
- Les premières notions de Git et GitHub
